# SonarX 6.2.0 — فروشگاه VPN و مرکز مدیریت

SonarX یک ربات مستقل فروش و مدیریت سرویس VPN است. طراحی پنل مدیریت با الهام از فهرست قابلیت‌های تصویری ارائه‌شده انجام شده و برند، ساختار و مسیر توسعه SonarX مستقل مانده است. **PasarGuard پنل اصلی و اولویت‌دار** است؛ Marzban و Marzneshin به‌عنوان پنل‌های ثانویه در دسترس‌اند.

## رابط کاربری نسخه ۶.۱ / هسته قابلیت‌های ۶.۲
رابط کاربری از حالت فهرست بلند دکمه‌ها به منوهای مرحله‌ای تبدیل شده است. صفحه اصلی کاربر و مرکز مدیریت با دکمه‌های شیشه‌ای دو ستونه نمایش داده می‌شوند؛ هر بخش زیرمنوی مختصر و مسیر بازگشت مشخص دارد.

**دو نوع کیبورد هرگز به‌عنوان دو منوی هم‌زمان استفاده نمی‌شوند.** دکمه‌های شیشه‌ای برای ناوبری و انتخاب‌ها هستند. هنگام ورود به مرحله ورود متن یا تأیید نهایی، دکمه‌های شیشه‌ای صفحه فعال حذف و Reply Keyboard مخصوص همان مرحله نمایش داده می‌شود. پس از پایان یا لغو عملیات، Reply Keyboard جمع می‌شود و صفحه شیشه‌ای بعدی باز می‌شود. در اولین اجرای `/start` بعد از بروزرسانی، کیبورد قدیمی نسخه قبل نیز پاک می‌شود.

برای جلوگیری از شلوغی گفتگو، صفحات اصلی تا حد امکان در همان پیام ویرایش می‌شوند. منوی مدیریت به هشت حوزه تقسیم شده است: نمای کلی، فروشگاه، مالی، کاربران، پشتیبانی، رشد، ظاهر و سیستم.

## امکانات کاربری
- خرید سرویس، مشاهده پلن و تأیید سفارش
- کیف پول و ثبت رسید پرداخت با تأیید/رد مدیر
- تحویل لینک اشتراک پس از ساخت موفق روی پنل
- مشاهده سرویس‌ها و سفارش‌ها
- تیکت پشتیبانی، آموزش و FAQ قابل تنظیم
- تمدید دستی و افزایش حجم سرویس از داخل ربات برای PasarGuard و Marzban؛ مدیر قیمت هر GB و هر روز را تعیین می‌کند
- کد هدیه اعتباری و کد تخفیف در مرحله خرید
- لینک دعوت اختصاصی و پاداش معرفی قابل تنظیم؛ چرخ شانس تاس/اسلات با محدودیت زمانی و قرعه‌کشی دستی
- اکانت تست رایگان با سقف استفاده هر کاربر و تنظیم حجم/مدت/گروه‌ها
- ساخت پلن دلخواه با نرخ‌گذاری هر GB و هر روز؛ پلن سفارشی فقط برای سازنده قابل خرید است
- انتخاب دسته‌بندی فروشگاه و اتصال هر پلن به دسته مشخص
- QR لینک اشتراک و بروزرسانی دستی مصرف/وضعیت/انقضا از پنل
- تأیید شماره با Contact تلگرام و امکان محدودسازی به شماره ایران؛ عضویت اجباری کانال
- کش‌بک خرید و شارژ، کمیسیون دعوت و پنل نمایندگی با درخواست و تأیید مدیر
- منوی اصلی شیشه‌ای دو ستونه؛ Reply Keyboard فقط در مراحل متن و تأیید حساس

## محدوده قابلیت‌ها و تطبیق با Mirza
ماتریس قابلیت‌ها، وضعیت اجرایی هر گزینه را مشخص می‌کند: 🟢 فعال، ⚪ اجرایی اما خاموش، 🧩 ماژول هنوز منتقل نشده است. گزینه‌های 🧩 عمداً قابل فعال‌سازی نیستند تا پنل وضعیت غیرواقعی نشان ندهد. قابلیت‌های منتقل‌شده و موارد باقی‌مانده به‌صورت دقیق در `FEATURE_MATRIX_FA.md` مستند شده‌اند.

در این نسخه، درگاه‌های آنلاین اختصاصی Mirza، Mini App و پنل وب، درایورهای پنل بیشتر، فروش دستی از انبار کانفیگ، ساخت گروهی واقعی، تغییر پروتکل/لوکیشن، عملیات on-hold، تمدید/همگام‌سازی زمان‌بندی‌شده و بکاپ خودکار هنوز منتقل نشده‌اند. این موارد به کلیدهای پذیرنده، callback عمومی، سرویس HTTP، API اختصاصی پنل یا worker زمان‌بندی‌شده نیاز دارند و در SonarX به‌عنوان قابلیت فعال نمایش داده نمی‌شوند.

## دیتابیس
- PostgreSQL 15/16 برای Production با Connection Pool از psycopg 3
- SQLite فقط برای توسعه و تست
- Migration با Alembic؛ نسخه‌های 6.0 و 6.2 migration افزایشی دارند و داده قبلی را حذف نمی‌کنند؛ نسخه 6.1 تغییر رابط کاربری و نسخه 6.2 انتقال قابلیت‌های هسته‌ای است
- تراکنش کیف پول، دفتر کل، شناسه مرجع یکتا و قفل ردیف PostgreSQL
- جداول کاربران، سرورها، پلن‌ها، سفارش‌ها، سرویس‌ها، رسیدها، دفتر کل، تنظیمات، تیکت‌ها، مدیران، گزارش ممیزی، تخفیف، هدیه، نمایندگان و کانال‌ها

## نصب تعاملی Ubuntu
این نسخه مشکل خواندن ورودی هنگام نصب با Pipe را رفع می‌کند؛ منو و پرسش‌ها از `/dev/tty` خوانده می‌شوند.

```bash
curl -fsSL https://raw.githubusercontent.com/amirtn9/sonarx/main/install.sh | sudo bash
```

برای نصب مستقیم بدون منو:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/amirtn9/sonarx/main/install.sh) install
```

## مدیریت CMD
```bash
sonarx status
sonarx doctor
sonarx logs -n 200 -f
sonarx restart
sonarx update
sonarx token-change
sonarx admins-set 123456789,987654321
sonarx admins
sonarx admin-add 123456789 --role operator
sonarx admin-remove 123456789
sonarx config show
sonarx config get BOT_TOKEN
sonarx config set CURRENCY_LABEL تومان
sonarx users
sonarx orders
sonarx settings
sonarx setting-set feature.shop_enabled 0
sonarx backup --output /root/sonarx-backup.dump
sonarx restore /root/sonarx-backup.dump --yes
```
`token-change` توکن جدید را به‌صورت مخفی دریافت می‌کند، با Telegram `getMe` اعتبارسنجی می‌کند و پس از ذخیره سرویس را Restart می‌کند. `admins-set` شناسه‌های عددی مدیر اصلی را در `.env` به‌روزرسانی و سرویس را Restart می‌کند. `config show` مقادیر محرمانه را ماسک می‌کند.

## امنیت
- توکن ربات، کلید Fernet و رمز پنل را در Git Commit نکنید.
- کلید Fernet را در بکاپ جداگانه و امن نگه دارید؛ گم‌شدن آن رمزهای پنل را غیرقابل‌بازیابی می‌کند.
- TLS پنل در حالت پیش‌فرض بررسی می‌شود؛ TLS را برای Production غیرفعال نکنید.
- در صورت Timeout پس از درخواست ساخت اکانت، سفارش به بررسی دستی می‌رود و ربات روی پنل دیگر درخواست ساخت تکراری نمی‌فرستد.
- قبل از فروش واقعی، ساخت کاربر، Group ID، لینک اشتراک، حجم و انقضا را روی پنل آزمایشی بررسی کنید.

## انتشار GitHub
