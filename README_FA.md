# SonarX 6.0 — فروشگاه VPN و مرکز مدیریت

SonarX یک ربات مستقل فروش و مدیریت سرویس VPN است. طراحی پنل مدیریت با الهام از فهرست قابلیت‌های تصویری ارائه‌شده انجام شده و برند، ساختار و مسیر توسعه SonarX مستقل مانده است. **PasarGuard پنل اصلی و اولویت‌دار** است؛ Marzban و Marzneshin به‌عنوان پنل‌های ثانویه در دسترس‌اند.

## تجربه دکمه‌های تلگرام
تلگرام در هر پیام فقط یک نوع `reply_markup` می‌پذیرد؛ بنابراین Reply Keyboard و Inline Keyboard را نمی‌توان روی یک پیام واحد هم‌زمان قرار داد. SonarX از ترکیب عملی آن‌ها استفاده می‌کند: Reply Keyboard پایدار برای ناوبری سریع کاربر و Inline Keyboard شیشه‌ای برای صفحات، تأییدها، فرم‌ها و عملیات مدیریتی.

## امکانات کاربری
- خرید سرویس، مشاهده پلن و تأیید سفارش
- کیف پول و ثبت رسید پرداخت با تأیید/رد مدیر
- تحویل لینک اشتراک پس از ساخت موفق روی پنل
- مشاهده سرویس‌ها و سفارش‌ها
- تیکت پشتیبانی، آموزش و FAQ قابل تنظیم
- تمدید دستی و افزایش حجم سرویس از داخل ربات برای PasarGuard و Marzban؛ مدیر قیمت هر GB و هر روز را تعیین می‌کند
- کد هدیه اعتباری و کد تخفیف در مرحله خرید
- لینک دعوت اختصاصی و پاداش معرفی قابل تنظیم؛ بازی تاس با پاداش قابل تنظیم؛ قرعه‌کشی دستی
- منوی Reply Keyboard پایدار به همراه منوی شیشه‌ای

## مدیریت داخل ربات
- داشبورد فروش، کاربران، رسیدهای معلق و تیکت‌ها
- مدیریت پلن، قیمت و وضعیت فروش
- مدیریت سرورها و اتصال پنل؛ PasarGuard اولویت اصلی
- جستجوی کاربر، مسدودسازی، شارژ کیف پول و پیام همگانی
- مدیریت مدیران دیتابیسی و ثبت Audit Log
- مدیریت دسته‌بندی‌ها، کد تخفیف، کد هدیه، نمایندگان و کانال‌ها
- مدیریت دکمه‌ها و ویرایش متن‌های ربات
- گزارش فروش، کاربران برتر و رویدادهای مدیریتی
- صفحه قابلیت‌ها با سوئیچ روشن/خاموش و ذخیره در دیتابیس
- صف سفارش‌های نامشخص برای جلوگیری از بازپرداخت یا ساخت تکراری ناایمن

## محدوده قابلیت‌ها
صفحه قابلیت‌ها شامل تنظیمات فعال/غیرفعال برای تمام گروه‌های تصویری است: فروش و سرویس، تست، تمدید، حجم/زمان، پلن سفارشی، پرداخت، تخفیف، هدیه، ارز، نمایندگی، ارجاع، قرعه‌کشی، پشتیبانی، پیام همگانی، آموزش، FAQ، تأیید شماره، عضویت اجباری، Mini App، QR، پروتکل، لوکیشن، لینک اشتراک، همگام‌سازی مصرف، سلامت سرور، بکاپ، ضدتقلب و پاکسازی. همه این گزینه‌ها در تنظیمات ذخیره می‌شوند؛ اما گزینه‌هایی که به API اختصاصی پنل، درگاه پرداخت، Mini App یا زمان‌بند نیاز دارند تا زمان تکمیل ماژول اجرایی مربوطه صرفاً سوئیچ تنظیمات/آماده‌سازی هستند و نباید به‌عنوان قابلیت عملیاتی کامل تلقی شوند. در این نسخه، تمدید گروهی/خودکار از API پنل، قرعه‌کشی خودکار، Mini App، درگاه پرداخت آنلاین و ساخت گروهی واقعی هنوز تکمیل نشده‌اند.

## دیتابیس
- PostgreSQL 15/16 برای Production با Connection Pool از psycopg 3
- SQLite فقط برای توسعه و تست
- Migration با Alembic؛ نسخه 6.0 migration افزایشی دارد و داده قبلی را حذف نمی‌کند
- تراکنش کیف پول، دفتر کل، شناسه مرجع یکتا و قفل ردیف PostgreSQL
- جداول کاربران، سرورها، پلن‌ها، سفارش‌ها، سرویس‌ها، رسیدها، دفتر کل، تنظیمات، تیکت‌ها، مدیران، گزارش ممیزی، تخفیف، هدیه، نمایندگان و کانال‌ها

## نصب تعاملی Ubuntu
این نسخه مشکل خواندن ورودی هنگام نصب با Pipe را رفع می‌کند؛ منو و پرسش‌ها از `/dev/tty` خوانده می‌شوند.

```bash
curl -fsSL https://raw.githubusercontent.com/amirtn9/sonarx/main/install.sh | sudo bash
```

برای نصب مستقیم بدون منو:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/amirtn9/sonarx/main/install.sh) install
```

## مدیریت CMD
```bash
sonarx status
sonarx doctor
sonarx logs -n 200 -f
sonarx restart
sonarx update
sonarx token-change
sonarx admins-set 123456789,987654321
sonarx admins
sonarx admin-add 123456789 --role operator
sonarx admin-remove 123456789
sonarx config show
sonarx config get BOT_TOKEN
sonarx config set CURRENCY_LABEL تومان
sonarx users
sonarx orders
sonarx settings
sonarx setting-set feature.shop_enabled 0
sonarx backup --output /root/sonarx-backup.dump
sonarx restore /root/sonarx-backup.dump --yes
```
`token-change` توکن جدید را به‌صورت مخفی دریافت می‌کند، با Telegram `getMe` اعتبارسنجی می‌کند و پس از ذخیره سرویس را Restart می‌کند. `admins-set` شناسه‌های عددی مدیر اصلی را در `.env` به‌روزرسانی و سرویس را Restart می‌کند. `config show` مقادیر محرمانه را ماسک می‌کند.

## مدیریت install.sh
با اجرای مجدد `sudo bash install.sh` مرکز عملیات نمایش داده می‌شود:
1. نصب/ترمیم
2. بروزرسانی GitHub
3. وضعیت سرویس و عیب‌یابی
4. مشاهده زنده لاگ‌ها
5. تغییر توکن ربات
6. تغییر شناسه مدیران اصلی
7. راهنمای CLI
8. حذف کد برنامه با حفظ دیتابیس

## نصب دستی توسعه
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m unittest discover -s tests -v
python -m compileall -q sonarx
bash -n install.sh
```

## امنیت
- توکن ربات، کلید Fernet و رمز پنل را در Git Commit نکنید.
- کلید Fernet را در بکاپ جداگانه و امن نگه دارید؛ گم‌شدن آن رمزهای پنل را غیرقابل‌بازیابی می‌کند.
- TLS پنل در حالت پیش‌فرض بررسی می‌شود؛ TLS را برای Production غیرفعال نکنید.
- در صورت Timeout پس از درخواست ساخت اکانت، سفارش به بررسی دستی می‌رود و ربات روی پنل دیگر درخواست ساخت تکراری نمی‌فرستد.
- قبل از فروش واقعی، ساخت کاربر، Group ID، لینک اشتراک، حجم و انقضا را روی پنل آزمایشی بررسی کنید.
